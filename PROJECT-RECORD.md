## Projects Presented

### Bench & Bolt
A Flask-based repair inquiry manager for a fictional bicycle repair shop. Staff can create inquiries, view saved requests, and update repair statuses.

- Technologies: Python, Flask, SQLite, pytest
- Testing: 14 automated tests passed.
- Peer review and final customer acceptance remain pending.
- Repository: https://github.com/SaroshAboobakker/repair-shop-studio

### Rock Paper Scissors
A Python game demonstrating game logic, input validation, automated testing, and browser-based interaction.

- Technologies: Python, pytest, Playwright
- Testing includes unit, integration, and browser-based tests.
- Repository: https://github.com/SaroshAboobakker/is218-rock-paper-scissors

### OOP Calculator
A command-line calculator using object-oriented programming and design patterns.

- Technologies: Python, pytest
- Testing: 14 tests passed with 100% code coverage.
- Repository: https://github.com/SaroshAboobakker/is218-oop-calculator

### J&J Chocolates Online Analysis
An Excel analysis of 50 online shopping transactions. The project examines customer spending, shopping behavior, and relationships between variables.
